# Đặc tả Giao diện & Design System WORD BRIDGE

- **Bảng màu chính thức**:
  - Deep Teal `#146466`: Điều hướng, tiêu đề nhấn, CTA chính.
  - Vermilion Red `#C92F1C`: Nhấn mạnh tiết chế, phần chữ `BRIDGE`.
  - Aqua `#5AABA9`: Thành phần hỗ trợ, focus ring.
  - Warm Ivory `#E2E2C4`: Bề mặt ấm, header email, thẻ nổi bật.
- **Typography đa ngôn ngữ**: Hỗ trợ đầy đủ tiếng Việt có dấu, chữ Hán (Noto Sans SC / PingFang SC / Microsoft YaHei), Cyrillic (Noto Sans), Latin và IPA.
- **Logo SVG**: Sử dụng HTML/text wordmark chuẩn màu và slot tích hợp `public/branding/word-bridge-logo.svg` với khoảng trống bảo vệ; lưu `logo-reference.jpg` làm tham chiếu.
- **Responsive**: Thiết kế hỗ trợ từ `360px`, `390px`, `430px`, `768px`, `1024px`, `1280px`, `1440px` đến `1920px` không tràn ngang.
- **Quản trị**: 100% tiếng Việt tại `/admin/*`.
